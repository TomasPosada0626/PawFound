# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades ni datos sensibles en Issues públicos.

Reporta de forma privada al propietario del repositorio con:

- Descripción del problema.
- Impacto potencial.
- Pasos de reproducción o prueba de concepto segura.
- Recomendación de mitigación, si la tienes.

Recibirás una confirmación y, cuando sea posible, una actualización sobre la evaluación. Por favor evita acceder, modificar o exponer datos de terceros.

# places.osm.json

Veterinarias del Valle de Aburrá exportadas de OpenStreetMap con
`go run ./cmd/api import-places` (apps/api). Se usan en el modo demostración de la app.

Datos © colaboradores de OpenStreetMap, disponibles bajo la
[Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/). Este extracto se
distribuye bajo la misma licencia; la app muestra la atribución en la ficha de cada lugar.
Para actualizarlo, se vuelve a importar y a exportar.

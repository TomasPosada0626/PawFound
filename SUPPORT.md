# Soporte

Para preguntas de uso, ideas de producto o ayuda no relacionada con vulnerabilidades, abre un Issue usando la plantilla más adecuada.

Para problemas de seguridad, sigue [SECURITY.md](SECURITY.md). Para reportes urgentes sobre una mascota real, usa los canales locales de emergencia, refugios y autoridades competentes; este repositorio no es un canal de respuesta de emergencia.
